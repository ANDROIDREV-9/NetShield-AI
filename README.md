## 1. Project Overview & Problem Statement

Modern enterprise defense infrastructure relies on automated machine learning pipelines to detect malicious cyber intrusions in line-rate network traffic. Traditional signature-based intrusion detection systems (IDS) fail against polymorphic payloads, encrypted command-and-control channels, and zero-day exploits.

**NetShield-AI** implements an end-to-end Machine Learning pipeline across all three academic tracks prescribed by the **23CSE301 Capstone Guidelines**:
1. **Track 1: Regression (Review 1)** — Predicting continuous network telemetry latency (`log1p(Flow Duration)`) across 10 regression algorithms.
2. **Track 2: Classification (Review 1 Part A + Review 2 Part B)** — Binary discrimination between benign traffic and cyber intrusions across 10 distinct classification algorithms.
3. **Track 3: Clustering (Review 2)** — Unsupervised discovery of latent traffic patterns and attack sub-clusters using K-Means and Agglomerative Hierarchical clustering without ground-truth labels during training.
4. **Bonus Deliverable (+2 Marks)** — Interactive full-stack web application featuring a **FastAPI REST inference backend** and a **Streamlit live operations dashboard**.

## 2. Dataset Description: CICIDS 2017

The benchmark dataset was generated by the Canadian Institute for Cybersecurity (University of New Brunswick):
- **Traffic Volume:** 2,830,743 bidirectional flow records parsed across 8 CSV files.
- **Dimensionality:** 79 raw telemetry features extracted via CICFlowMeter, pruned and engineered down to 30 top predictors.
- **Attack Classes (15 categories):** BENIGN (80.3%), DoS Hulk, PortScan, DDoS, DoS GoldenEye, FTP-Patator, SSH-Patator, DoS Slowloris, DoS Slowhttptest, Botnets, Web Attacks (Brute Force, XSS, SQLi), Infiltration, and Heartbleed.
- **Zero Data Leakage Protocol:** All standard scalers and SMOTE balance generators are fitted strictly on training partitions; ground-truth labels are isolated from unsupervised clustering until post-hoc cross-tabulation.

## 5. Bonus Deliverable: Interactive Web Application (+2 Marks)

The project includes a production-grade interactive GUI designed with modern software engineering principles:
- **Backend (FastAPI):** High-speed asynchronous REST API providing validation, input scaling, and sub-millisecond model predictions.
- **Frontend (Streamlit):** Security Operations Center (SOC) dashboard allowing live payload testing, model switching, threshold adjustment, and risk analysis.

### Launching the Application Locally

1. **Option A — Unified Single-Command Launcher:**
```bash
python app/app.py
```

2. **Option B — Launch Backend and Frontend Separately:**
```bash
# Terminal 1: Start FastAPI REST Backend (Port 8000)
uvicorn app.backend:app --host 0.0.0.0 --port 8000 --reload

# Terminal 2: Start Streamlit Frontend (Port 8501)
streamlit run app/frontend.py
```

Access the local dashboard at **http://localhost:8501** (API documentation available at **http://localhost:8000/docs**).

### Deploying on Streamlit Community Cloud (Public Web URL)

The application is pre-configured for 1-click deployment on **Streamlit Community Cloud**:
1. Navigate to **[share.streamlit.io](https://share.streamlit.io/)** and sign in with your GitHub account.
2. Click **"New app"**.
3. Configure the deployment settings:
   - **Repository:** `ANDROIDREV-9/NetShield-AI`
   - **Branch:** `master`
   - **Main file path:** `streamlit_app.py`
4. Click **"Deploy!"**.
Streamlit Cloud automatically provisions the container, installs dependencies from `requirements.txt`, loads the pre-trained models from `models/`, and assigns a live public URL (e.g., `https://netshield-ai.streamlit.app/`).

### Automated App Testing
Run the test suite to verify end-to-end functionality:
```bash
python tests/test_app.py
```
All endpoints and real attack classifications pass with 100% accuracy.
